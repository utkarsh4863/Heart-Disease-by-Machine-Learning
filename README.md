# ❤️ Heart Disease Prediction using Machine Learning

## 📌 Project Overview

Heart Disease Prediction is a Machine Learning web application that predicts whether a person is at risk of heart disease based on various medical parameters. The application provides an easy-to-use interface where users can enter patient information and receive an instant prediction.

The project combines data preprocessing, feature engineering, machine learning modeling, and web deployment using Streamlit.

## 📊 Input Parameters

The model uses the following medical attributes:

* Age
* Sex
* Resting Blood Pressure
* Cholesterol
* Fasting Blood Sugar
* Chest Pain Type
* Resting ECG
* Maximum Heart Rate
* Exercise Angina
* Oldpeak
* ST Slope

## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/utkarsh4863/Heart-Disease-by-Machine-Learning.git
```

Move into the project directory:

```bash
cd Heart-Disease-by-Machine-Learning
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
